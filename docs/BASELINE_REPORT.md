# 同源事件聚类实验记录

本报告保留原项目于 2026 年 7 月进行的基线实验口径。数据和模型不包含在仓库中，下列数值来自已有实验记录，尚未在本次整理中重新复算。

## 方法

将新闻正文编码为 `BAAI/bge-large-zh-v1.5` 向量，通过 FAISS 检索近邻，以相似度阈值建图，并将连通分量作为同源事件组。评估指标使用重复/转载关系作为参考标签；阈值应随数据、模型和应用目标重新选择。

## 数据与结果

- **转载检索**：在 1,525 篇公司原文中检索 654 篇有对应关系的转载，Recall@1 为 97.7%（639/654），Recall@10 为 99.7%。
- **公司维度聚类**：原文与转载合计 2,524 篇，参考标签包含 422 组、覆盖 1,082 篇文章。图聚类阈值为 0.94 时，purity 为 0.964，ARI 为 0.791，NMI 为 0.989，组检测率为 97.6%。
- **行业维度聚类**：原文与转载合计 1,056 篇，参考标签包含 212 组、覆盖 583 篇文章。阈值为 0.92 时，purity 为 0.9451，ARI 为 0.8530，NMI 为 0.9861，组检测率为 97.17%。

在公司维度同口径对比中，HDBSCAN 的 purity 和 ARI 更高（0.992 / 0.903），但生成的簇数更多（728，图聚类为 532），组检测率为 95.3%。这体现了不同指标之间的取舍；不能仅凭某一指标断言一种方法在所有数据上更优。

## 复现条件

需要原始标注工作簿、对应的 BGE 模型和 Python 完整依赖；输入文件名与工作表位置见 `src/config/config.yaml`。相关评估脚本位于 `scripts/evaluate_dedup.py`、`scripts/optimize_clustering.py` 和 `scripts/pipeline_full_eval.py`。数据、模型版本或参数改变后，应重新计算向量和指标。仓库内的虚构样例仅用于验证流程，不参与这些指标。
